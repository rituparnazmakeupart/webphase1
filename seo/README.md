# SEO / GEO / AEO documentation

## URL strategy
Canonical URLs use `https://www.rituparnazmakeup.com` without `/index.html`. Directory landing pages use trailing slashes: `/services/` and `/makeup-academy/`.

## Page intent
- Home: brand entity + local makeup artist + services + academy discovery.
- Services index: broad makeup service discovery.
- Service pages: intent-specific local landing pages for each supplied service.
- Academy pages: course, training, certification and real-client practice intent.
- About: entity and brand context.
- Contact: location, phone, WhatsApp, map and enquiry intent.
- FAQ: factual question answering.

## Metadata
Every page has a unique title, description, canonical, robots directive, Open Graph data and Twitter summary-card metadata.

## Structured data
The site uses LocalBusiness, WebSite and WebPage JSON-LD. Service pages also use Service schema. FAQ uses FAQPage schema. No fabricated reviews, ratings, aggregate ratings, awards, prices or approvals are included.

## Local SEO
The primary entity location is Sultanpur, near RamSita Mandir, Paschim Medinipur, West Bengal, India, 721149. Relevant nearby locality names are included contextually rather than as doorway pages: Debra, Kharagpur, Medinipur, Balichak, Madpur, Basantapur, Panskura, Kolaghat and Radhamohanpur.

## GEO / AI search
Entity-first copy makes the WHO, WHAT and WHERE explicit and keeps service names close to their descriptions. Avoid stuffing locality names.

## Images
Use meaningful image filenames and alt text. All supplied portfolio photos are normalised to WebP and stored under `assets/images/work/<category>/`.

## Expansion opportunities
Future location pages can be added under `/locations/kharagpur/`, `/locations/debra/`, `/locations/medinipur/` only when each has unique, useful local information.
